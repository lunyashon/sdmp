# DMP — прототипы интерфейсов (для Виталия)

Два независимых прототипа, каждый — рабочая статика на моковых данных, HTML разложен на HTML/CSS/JS для удобства интеграции.

## dmp-worker-config/

Настройка Worker: справочники (источники, операторы), маршрутизация (дробление с teg-логикой, отправка партнёрам, работа с дублями/униками), интеграции (входящий/исходящий трафик, реестр проектов Скорозвона, Скорозвон→Битрикс), обогащение (контроль региона/оператора/дедупликации).

Открыть: `dmp-worker-config/index.html`

## dmp-archive-export/

Архивная выгрузка строк: динамический конструктор фильтров, настраиваемые колонки таблицы, карточка строки (клик по UUID) с единым таймлайном и конфигурируемым набором полей, сохранённые фильтры, экспорт.

Открыть: `dmp-archive-export/index.html`

## Важно

- Все данные — моковые (генерируются в script.js при загрузке страницы), реального API нет.
- Контракт API, который нужен для подключения — описан внизу каждой страницы, в жёлтой плашке.
- Прототипы не адаптированы под мобильные экраны — только desktop.
- Актуальная версия на момент сборки архива: 31.08.2026, после разбора архитектуры дублей/уников с Даней и цикла правок с Денисом.
